# Stipz Frontend

Frontend Angular do sistema Stipz para gerenciamento de reservas de salas,
recursos e eventos.

## Requisitos

- Node.js
- npm
- Backend Stipz executando em `http://localhost:8080`

## Executar localmente

```bash
npm install
npm start
```

A aplicação estará disponível em `http://localhost:4200`.

## Build

```bash
npm run build
```

Os arquivos compilados serão gerados em `dist/`.
